3. AI Code Snippet Manager ✅ (chosen) — Save, tag, search, and get AI explanations for reusable code snippets

## Problem Statement
Developers waste significant time searching through old projects, notes, and browser bookmarks to find code they have already written. There is no simple tool that lets developers save, organize, and instantly retrieve reusable code snippets with AI-powered explanations and tag suggestions.

## MVP Features
- Save a code snippet with title, language, and description
- AI automatically suggests relevant tags and a short explanation for each snippet
- Search and filter snippets by language, tag, or keyword
- View snippet with syntax highlighting and copy-to-clipboard button
- Delete or edit saved snippets
