# User Stories - AI Code Snippet Manager

## User Story 1
As a developer, I want to save a code snippet with a title, programming language, and description so that I can store reusable code in one organized place.

## User Story 2
As a developer, I want the AI to automatically generate relevant tags and a plain-English explanation for my snippet so that I spend less time manually documenting my code.

## User Story 3
As a user, I want to search snippets by keyword across titles and descriptions so that I can instantly find the code I need without browsing the entire library.

## User Story 4
As a user, I want to filter snippets by programming language or tag so that I can narrow results to what is relevant to my current task.

## User Story 5
As a user, I want to view a snippet with syntax highlighting and a one-click copy-to-clipboard button so that I can use the code immediately without reformatting.

## User Story 6
As a user, I want to edit an existing snippet's title, code, language, or description so that I can keep my library accurate as my code evolves.

## User Story 7
As a user, I want to delete a snippet I no longer need so that my library stays clean and relevant.

## User Story 8
As a user, I want to organize snippets into named collections so that I can group related snippets by project or topic.
