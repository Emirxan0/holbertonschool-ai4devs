# User Stories - AI Code Snippet Manager

## User Story 1
As a developer, I want to save a code snippet with a title, language, and description so that I can store reusable code in one organized place.

## User Story 2
As a user, I want the AI to automatically suggest relevant tags and a short explanation for my saved snippet so that I spend less time manually documenting my code.

## User Story 3
As a user, I want to search snippets by keyword so that I can instantly find the code I need without browsing through everything.

## User Story 4
As a user, I want to filter snippets by programming language or tag so that I can narrow down results to what is relevant to my current task.

## User Story 5
As a user, I want to view a snippet with syntax highlighting and a copy-to-clipboard button so that I can use the code immediately without reformatting.

## User Story 6
As a user, I want to edit an existing snippet's title, code, language, or description so that I can keep my library up to date as my code evolves.

## User Story 7
As a user, I want to delete a snippet I no longer need so that my library stays clean and relevant.

## User Story 8
As a user, I want to organize snippets into collections so that I can group related snippets by project or topic.

## User Story 9
As a user, I want to see an AI-generated explanation of any snippet on demand so that I can quickly understand code I saved weeks ago.

## User Story 10
As a user, I want to see my most recently saved and most frequently accessed snippets on a home dashboard so that I can reach my most-used code instantly.
