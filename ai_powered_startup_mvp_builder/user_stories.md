# User Stories - Smart Task Manager

## User Story 1
As a freelancer, I want to create a new task with a title, description, priority, and due date so that I can track all my work items in one organized place.

## User Story 2
As a user, I want to view all my tasks on a Kanban board with columns (To Do, In Progress, Done) so that I can see the overall status of my work at a glance.

## User Story 3
As a user, I want to manage task details (edit title, description, priority, due date, or delete the task) so that I can keep my board accurate as requirements evolve.

## User Story 4
As a user, I want the system to automatically suggest a priority level based on the task deadline and current workload so that I can focus on the most critical work without manual effort.

## User Story 5
As a user, I want to receive a visual alert when a task deadline is within 24 hours or overdue so that I never miss an important commitment.

## User Story 6
As a user, I want to filter and search tasks by status, priority, due date, or keyword so that I can instantly locate relevant tasks without scrolling through the entire list.

## User Story 7
As a user, I want to view a progress dashboard showing completed percentage, overdue count, and a 7-day productivity trend so that I can evaluate my performance over time.

## User Story 8
As a user, I want to assign a category and tags to each task so that I can group and cross-reference related work items across different projects.
