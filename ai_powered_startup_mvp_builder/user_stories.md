# User Stories - Smart Task Manager

## User Story 1
As a freelancer, I want to create a new task with a title, description, priority, and due date so that I can track my work items in one place.

## User Story 2
As a user, I want to view all my tasks on a Kanban board with columns (To Do, In Progress, Done) so that I can see the overall status of my work at a glance.

## User Story 3
As a user, I want to drag and drop tasks between Kanban columns so that I can update task status quickly without clicking through menus.

## User Story 4
As a user, I want the system to automatically suggest a priority level (high, medium, low) based on the task deadline and my current workload so that I can focus on the most important work first.

## User Story 5
As a user, I want to receive a visual alert when a task deadline is within 24 hours or overdue so that I never miss an important deadline.

## User Story 6
As a user, I want to filter tasks by status, priority, or due date so that I can quickly find the tasks most relevant to my current focus.

## User Story 7
As a user, I want to search tasks by keyword so that I can locate a specific task without scrolling through the entire list.

## User Story 8
As a user, I want to view a progress dashboard showing total tasks, completed percentage, overdue count, and a 7-day productivity trend so that I can evaluate my performance over time.

## User Story 9
As a user, I want to edit an existing task's details (title, description, priority, due date) so that I can keep task information up to date as requirements change.

## User Story 10
As a user, I want to delete a task so that I can remove work items that are no longer relevant and keep my board clean.

## User Story 11
As a user, I want the application to save my tasks automatically in the browser so that my data persists between sessions without requiring an account.
