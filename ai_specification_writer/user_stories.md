# User Stories

### User Story 1
As a passenger, I want to search for nearby drivers so that I can find a quick ride.

**Acceptance Criteria**:
- User enters pickup and destination.
- System displays available drivers within 5 km.
- Ride can be booked in under 2 minutes.

**Priority**: MVP

---

### User Story 2
As a driver, I want to list my available seats so that I can share travel costs with others.

**Acceptance Criteria**:
- Driver sets the price per seat.
- Driver specifies the departure time and route.
- System confirms the listing is visible to passengers.

**Priority**: MVP

---

### User Story 3
As a user, I want to pay for my ride through the app so that I don't need to carry cash.

**Acceptance Criteria**:
- System supports credit card and digital wallets.
- User receives a digital receipt after payment.
- Payment is only processed after the ride starts.

**Priority**: High

---

### User Story 4
As a passenger, I want to see the driver's rating so that I can feel safe before booking.

**Acceptance Criteria**:
- Ratings are displayed as stars (1-5).
- User can read at least three recent comments.
- System hides drivers with a rating below 3 stars.

**Priority**: High

---

### User Story 5
As a driver, I want to set a maximum number of passengers so that my car is not overcrowded.

**Acceptance Criteria**:
- Driver selects capacity (1-4 seats).
- System prevents further bookings once capacity is reached.

**Priority**: Medium

---

### User Story 6
As a user, I want to receive real-time notifications about my ride status so that I am always updated.

**Acceptance Criteria**:
- Notifications sent for booking confirmation.
- Notifications sent when the driver is 2 minutes away.

**Priority**: Medium

---

### User Story 7
As an admin, I want to block users who violate safety rules so that the platform remains secure.

**Acceptance Criteria**:
- Admin can search for users by ID or email.
- Admin has a "Block" button with a reason field.
- Blocked users cannot log in.

**Priority**: Low

---

### User Story 8
As a user, I want to see an estimate of the CO2 emissions saved so that I can see my environmental impact.

**Acceptance Criteria**:
- System calculates savings based on trip distance.
- Impact is displayed on the user profile.

**Priority**: Low
