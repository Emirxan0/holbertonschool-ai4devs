# Monolithic Architecture

*   **Frontend App**: Provides the user interface for both mobile and web platforms.
*   **Backend Monolith**: A single, unified server that handles all application logic and requests.
*   **Authentication Module**: Manages user registration, login, and secure session handling.
*   **Itinerary Planning Module**: The core AI logic that generates personalized travel suggestions.
*   **Payment Integration Module**: Processes all financial transactions for flights and hotels.
*   **Collaboration Service**: Enables multiple users to edit a single trip itinerary simultaneously.
*   **Notification Service**: Handles push notifications and emails for trip updates.
*   **Central Database**: A single, shared database that stores all user profiles, trips, and settings centrally.
